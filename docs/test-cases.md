# ตารางกรณีทดสอบ (Test Cases) — Clinic Flow

ใช้วัดเกณฑ์ความสำเร็จข้อ 1 **"ระบบทำงานได้ครบฟังก์ชัน ≥ 90%"**

## วิธีใช้ตารางนี้

1. ทดสอบทีละกรณีตาม "ขั้นตอน" แล้วเทียบกับ "ผลที่คาดหวัง"
2. กรอกคอลัมน์ **ผล** เป็น ✅ (ผ่าน) หรือ ❌ (ไม่ผ่าน) และจดสิ่งที่เกิดขึ้นจริงในคอลัมน์ **หมายเหตุ** ถ้าไม่ผ่าน
3. คอลัมน์ **ทดสอบโดย** บอกว่าทดสอบด้วยวิธีใด
   - **Postman** = มีใน `docs/postman/ClinicFlow.postman_collection.json` รันแล้วตรวจผลอัตโนมัติ
   - **Unit** = มีในเทสต์อัตโนมัติ `npm test` (โฟลเดอร์ `tests/`)
   - **UI** = ทดสอบด้วยมือผ่านหน้าเว็บ
4. คำนวณผลรวมที่ท้ายเอกสาร

> ใช้ข้อมูลผู้ป่วยสมมติเท่านั้น ผู้ป่วยที่สร้างระหว่างทดสอบลบออกจากระบบไม่ได้
