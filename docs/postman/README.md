# ทดสอบ API ด้วย Postman

ชุดทดสอบ 41 request ครอบคลุมเข้าสู่ระบบ บัญชีผู้ใช้ ผู้ป่วย คลังยา คิว เตือนแพ้ยา ยกเลิกคิว และภาพรวมคลินิก
รหัสกรณีทดสอบ (TC-xxx) ตรงกับ `docs/test-cases.md`

## วิธีใช้

1. เปิดเซิร์ฟเวอร์ `npm run dev`
2. ใน Postman กด **Import** แล้วเลือกทั้งสองไฟล์ในโฟลเดอร์นี้
   - `ClinicFlow.postman_collection.json`
   - `ClinicFlow.postman_environment.json`
3. เลือก environment **Clinic Flow (local)** ที่มุมขวาบน แล้วกรอก `adminPassword` เป็นรหัสผ่านของบัญชีเจ้าของคลินิก (ค่านี้ไม่ได้ถูกเก็บในไฟล์)
4. คลิกขวาที่ collection **Clinic Flow API** → **Run collection** → กด **Run** (ต้องรันตามลำดับ เพราะ request หลังใช้ข้อมูลจาก request ก่อนหน้า)
5. ถ่ายภาพหน้าจอผลการรันไว้ใช้ในรายงาน

## สิ่งที่ collection ทำกับข้อมูล

ทุกครั้งที่รันจะสร้างข้อมูลทดสอบใหม่ที่มีเลขรอบต่อท้าย ได้แก่ บัญชีพยาบาล `pm_nurse_xxxxxx` ผู้ป่วย "ทดสอบ Postmanxxxxxx" และยา `PM-xxxxxx`
ตอนท้ายจะปิดบัญชีพยาบาลทดสอบให้อัตโนมัติ แต่ผู้ป่วยและยาจะยังอยู่ เพราะระบบไม่มีการลบ

**ใช้กับฐานข้อมูลทดสอบ หรือฐานข้อมูลที่ยังไม่มีข้อมูลจริงเท่านั้น**

ทดสอบกับลิงก์ Cloudflare Tunnel ได้ด้วย โดยเปลี่ยน `baseUrl` ใน environment เป็นลิงก์ `https://….trycloudflare.com`
