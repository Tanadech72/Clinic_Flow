# รายการยาเริ่มต้นสำหรับคลินิกเวชกรรมทั่วไป

รายการใน starter-medicines.json เป็นตัวอย่างข้อมูลคลังสำหรับโปรเจกต์ ให้แพทย์เจ้าของคลินิกเลือกตามขอบเขตบริการและผู้ป่วยที่ดูแล ไม่ใช่รายการที่ทุกคลินิกต้องจัดซื้อครบ หรือคำแนะนำการรักษา

ตรวจสอบชื่อสามัญและรูปแบบยาจาก [บัญชียาหลักแห่งชาติของ อย.](https://ndi.fda.moph.go.th/drug_national/search)
ความแรงในรายการเป็นตัวอย่างผลิตภัณฑ์ ต้องเทียบชื่อ รูปแบบ ความแรง และขนาดบรรจุกับฉลากยาที่รับเข้าจริงก่อนใช้

รัน `npm run seed:medicines` เพื่อเพิ่มเฉพาะรายการที่ยังไม่มี ระบบตรวจชื่อและรหัสรวมรายการที่ปิดใช้งานแล้ว เพื่อรักษาข้อมูลเดิม

- จำนวนเริ่มต้น 0 ให้รับเข้าด้วยเมนูรับยาเข้าสต๊อกตามจำนวนจริง
- ราคาเริ่มต้น 0 สามารถรัน `node set-medicine-prices.js` เพื่อใส่ราคาขายตัวอย่างสำหรับโปรเจกต์ เฉพาะรายการที่ราคายังเป็น 0 ราคาเป็นเงินบาทต่อหน่วย ไม่ใช่ราคาตลาดหรือราคาจัดซื้อ ต้องปรับตามผลิตภัณฑ์ ขนาดบรรจุ และราคาของคลินิกจริง
- วันหมดอายุเริ่มต้นว่าง ให้บันทึกตามฉลากของยาจริง
- จุดสั่งซื้อเริ่มต้น 10 เป็นค่าเริ่มต้นของระบบ ให้ปรับให้เหมาะกับแต่ละรายการ
- รายการนี้ไม่มีวิธีใช้หรือคำสั่งรักษาอัตโนมัติ หมอเป็นผู้สั่งยาในแต่ละการรักษา
